# 慢记发布与验收

## 原 Grok 网站

`manji.grok.me` 是原托管域名，代码本身是通用 Node.js + SQLite 应用，不依赖 Grok SDK。
修改 GitHub 不代表该网址会自动更新。需让拥有原 Grok 项目的人同步本次代码并重新发布。
如果 Grok 无法运行 Node.js 后端或提供持久化磁盘，不要仅把 public 文件夹发布成静态站，也不要把 SQLite 数据放到会被回收的临时磁盘。

发布前先备份线上数据库及媒体目录；SQLite 在线备份应使用 SQLite backup API，或停服务后复制整个数据目录（包含 WAL 文件）。不要用本机测试库覆盖线上数据。

## 必须一致的配置

```env
ONCHAIN_RPC_URL=https://rpc.botchain.ai
ONCHAIN_CHAIN_ID=677
ONCHAIN_CONTRACT=0xDf6d55959BD6abCdE5750D800F782637115b672D
ONCHAIN_EXPLORER=https://scan.botchain.ai
ONCHAIN_RELAYER_KEY=
PUPPY_IDENTITY_CONTRACT=
```

用户钱包直发不需要服务器私钥。小狗身份合约属于另一项功能，归属未确认前保持关闭。
配置优先级：平台环境变量 > .env.local > .env > 代码默认值。
已有平台变量若指向别的地址，必须在平台修正；修改仓库默认值不会覆盖它。
通过部署平台设置强 ADMIN_PASSWORD，私钥及密码不要写进仓库、前端或公开截图。

## 普通服务器运行

完整仓库放到服务器，安装 Node.js 24，在仓库根目录配置 `.env` 后运行：

```sh
npm start
```

钱包直发路径没有必需的第三方 npm 依赖。若另行启用服务器 relayer，才需要安装可选 ethers 依赖。
HTTPS 域名反向代理到该 Node 服务，默认端口 4173。不能只发布 public/，否则账号和交易接口不可用。

## Docker 备选（需要已有支持 Docker 的服务器）

仓库提供 Dockerfile 和 compose.yaml，启动：

```sh
docker compose up -d --build
```

先在服务器私密 `.env` 中设置 ADMIN_PASSWORD。compose 会要求该变量，不能沿用公开默认管理员密码。
数据保存在 named volume `manji-data`；迁移原站需单独导入备份，不会自动带入原数据。
容器监听映射到 127.0.0.1:4173，由现有 HTTPS 反向代理对外发布。此配置未在本次环境实际构建测试。

## 发布验收门槛

1. 首屏可见 Connect Wallet；MetaMask/OKX 可选，授权后显示地址。
2. 能切到 677，拒绝切链时不会继续广播。
3. 页面及接口显示同一指定合约，浏览器链接正确。
4. 个人日记/约定的哈希能经用户钱包签名发送。
5. Pending / Failed / Success 区分正确；成功回执目标与 Sealed 事件匹配。
6. 保存完整交易 Hash 和录屏；部署交易不替代业务调用。
7. 无钱包、RPC 故障、后端离线和合约权限拒绝均有明确提示。

本地测试通过不代表线上发布完成，更不代表旧合约允许任意用户调用。
